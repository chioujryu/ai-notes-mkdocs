當談到模型的預測準確度時，**均方誤差 (MSE)** 和 **平均絕對誤差 (MAE)** 是兩個常用的評估指標。這兩個指標都衡量模型預測與真實值之間的誤差，但它們的計算方式不同。

### 1. **均方誤差 (Mean Squared Error, MSE)**

均方誤差（MSE）是所有預測誤差的平方的平均值。公式如下：

[
MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
]

其中：

* ( n ) 是樣本的數量。
* ( y_i ) 是第 (i) 個樣本的真實值（標籤）。
* ( \hat{y}_i ) 是第 (i) 個樣本的預測值。
* ( (y_i - \hat{y}_i) ) 是預測誤差。

#### **運算過程範例** ：

假設有 3 個樣本，真實值 ( y = [3, -0.5, 2] )，預測值 ( \hat{y} = [2.5, 0.0, 2] )，則可以依照以下步驟計算 MSE：

1. 計算誤差：( y_i - \hat{y}_i )
   * 第一個樣本誤差：( 3 - 2.5 = 0.5 )
   * 第二個樣本誤差：( -0.5 - 0.0 = -0.5 )
   * 第三個樣本誤差：( 2 - 2 = 0 )
2. 計算誤差的平方：( (y_i - \hat{y}_i)^2 )
   * 第一個樣本誤差平方：( (0.5)^2 = 0.25 )
   * 第二個樣本誤差平方：( (-0.5)^2 = 0.25 )
   * 第三個樣本誤差平方：( (0)^2 = 0 )
3. 計算誤差平方的平均值：
   [
   MSE = \frac{1}{3} \left( 0.25 + 0.25 + 0 \right) = \frac{0.5}{3} = 0.1667
   ]

因此，這組數據的 MSE 值為  **0.1667** 。

### 2. **平均絕對誤差 (Mean Absolute Error, MAE)**

平均絕對誤差（MAE）是所有預測誤差的絕對值的平均值。公式如下：

[
MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
]

其中：

* ( n ) 是樣本的數量。
* ( y_i ) 是第 (i) 個樣本的真實值（標籤）。
* ( \hat{y}_i ) 是第 (i) 個樣本的預測值。
* ( |y_i - \hat{y}_i| ) 是預測誤差的絕對值。

#### **運算過程範例** ：

使用與前面相同的數據：真實值 ( y = [3, -0.5, 2] )，預測值 ( \hat{y} = [2.5, 0.0, 2] )，計算 MAE 的過程如下：

1. 計算誤差的絕對值：( |y_i - \hat{y}_i| )
   * 第一個樣本誤差：( |3 - 2.5| = 0.5 )
   * 第二個樣本誤差：( |-0.5 - 0.0| = 0.5 )
   * 第三個樣本誤差：( |2 - 2| = 0 )
2. 計算誤差的絕對值的平均值：
   [
   MAE = \frac{1}{3} \left( 0.5 + 0.5 + 0 \right) = \frac{1}{3} = 0.3333
   ]

因此，這組數據的 MAE 值為  **0.3333** 。

---

### 比較 MSE 和 MAE

* **MSE** 對大誤差更為敏感，因為誤差的平方使得較大的誤差影響較大。這使得 MSE 更適合用來處理對大誤差敏感的問題。
* **MAE** 更為直觀，表示的是誤差的平均絕對大小，不會像 MSE 那樣對大誤差進行過度放大。因此，MAE 更適合於對誤差分布較為均勻的問題。

總結來說，兩者各有優缺點，選擇使用哪一個指標取決於你對預測準確度的需求和數據的特性。
